GUIDE 使い方
1
商品URLを入力
紹介したい商品ページのURLを PRODUCT URL に貼り付け。お試しなら https://example-shop.com/products/mirai-serum でもOK。
2
「生成開始」を押す
走査→解析→生成と自動で進み、縦型ショート用の台本が3タイプ同時に完成します(A 問題提起型 / B ビフォーアフター型 / C ランキング型)。
3
コピーして撮影に使う
各カードの COPY、または 3本まとめてコピー。秒数タイムコード付きなので、そのまま撮影台本・テロップ案として使えます。
4
気に入らなければ作り直す
↻ 再生成 を押すたびに別パターンの台本が出ます。1タイプだけの作り直しもOK。
TIPS もっと便利に
  • 精度を上げる: URL欄の下「▸ 商品名・特徴を手動入力」に商品名と推しポイントを入れると、台本にそのまま反映されます(URLからの推定より優先)。
  • ジャンル自動判定: URLや商品名から美容/ガジェット/健康/グルメを判定し、悩み・ベネフィットの語彙が切り替わります。
  • 履歴: 生成結果は自動で保存(直近10件)。HISTORY からいつでも復元できます。
  • 投稿予約: 生成後に表示される予約枠は、現在時刻から次のゴールデンタイム(7時/12時/19時/21時)を自動で割り当てています。
  • AI生成モード: API ⚙ にAnthropic APIキーを設定すると、本物のAIによる台本生成に切り替わります(ローカルで開いた場合のみ。未設定でも内蔵テンプレートで動きます)。
  • 尺の切り替え: URL欄の横で15秒/30秒/55秒を選べます。15秒は「フック→核心→CTA」まで自動圧縮。
  • CTAは2案(A/B)出ます: 反応の良い方を次回に使うと伸びが安定します。
  • 生成後にできること: 「📅 予約を.icsで保存」でカレンダーに投稿予定を登録、「🖨 撮影指示書」でカット割り・素材メモ欄付きの印刷用シート(PDF保存可)を出力。
  • 連携ツール: ヘッダーの HOOK(フック文20本生成)/REPLY(コメント返信案)/BOARD(商品リサーチ管理)も使えます。BOARDの「台本を作る」からここに商品情報を引き継げます。
  • スマホの方: RESEARCHのタイトルをタップすると走査ログが展開されます。
