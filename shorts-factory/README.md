# SHORTS FACTORY SUITE

縦型ショート動画の「リサーチ → 台本 → 投稿予約」を一気通貫でこなす4ツール(すべて1ファイル完結・ブラウザで開くだけ)。

| ファイル | ツール | 役割 |
|---|---|---|
| `index.html` | **SHORTS FACTORY** | 商品URLから3タイプ×3尺の台本を同時生成するメインダッシュボード |
| `hook-factory.html` | **HOOK FACTORY** | 冒頭2秒のフック文を20本生成してS/A/Bランクで採点 |
| `reply-factory.html` | **REPLY FACTORY** | 動画コメントを5分類して返信案を量産 |
| `research-board.html` | **RESEARCH BOARD** | アフィ商品の候補を単価・ショート適性で管理。「台本を作る」で本体に引き継ぎ |

黒×琥珀色のターミナル調UIで、以下のワークフローを再現しています。

**01 走査 → 02 解析 → 03 生成 → 04 予約**

## 機能

- **RESEARCH パネル** — バズ動画の解析本数カウンター、伸びているフック型(問題提起 / 変化・比較 / ランキング)のグラフ、YouTube / TikTok 走査ログのライブフィード
- **GENERATOR** — 商品ページのURLを入力して「生成開始」を押すと、縦型ショート用の台本を3タイプ同時生成
  - A 問題提起型
  - B ビフォーアフター型
  - C ランキング型
- **バリエーション生成** — フック・展開・CTAを複数パターンからランダム選択。各カードの「↻ 再生成」で1本ずつ作り直し可能
- **ジャンル自動判定** — URL・商品名から美容/ガジェット/健康/グルメを判定し、台本の語彙を切り替え
- **商品情報の手動入力** — 商品名・特徴を任意入力でき、台本に反映(URL推定より優先)
- **投稿予約枠の自動計算** — 現在時刻から次のゴールデンタイム(7時/12時/19時/21時)を3枠割り当て
- **履歴** — 生成結果を直近10件までlocalStorageに保存し、HISTORYから復元
- **一括コピー** — 3本まとめて/1本ずつクリップボードにコピー
- **尺の切り替え** — 15秒/30秒/55秒。15秒は「フック→核心→CTA」に自動圧縮
- **CTA A/B 2案出し** — 各台本のCTAを2パターン併記。反応の良い方を採用できる
- **ハッシュタグ階層提案** — ジャンル別に大タグ2+中タグ3+小タグ2を自動構成
- **投稿予約の .ics 書き出し** — 予約枠をカレンダーファイルでダウンロードし、スマホのカレンダー/リマインダーに登録(30分前アラーム付き)
- **撮影指示書の印刷** — カット割り・テロップ案・素材メモ欄付きのシートを印刷/PDF保存
- **商品ページ本文の取り込み(任意)** — CORSプロキシURLを設定すると、API生成時に商品ページの本文をClaudeに渡して精度を上げられる
- **バズ走査の実データ化(任意)** — YouTube Data APIキーを設定すると、左パネルの走査フィードに直近7日の急上昇ショートの実タイトルが流れる
- **使い方ガイド** — 初回アクセス時に自動表示。ヘッダーの「? 使い方」からいつでも4ステップガイド+TIPSを呼び出せる
- **Claude API連携(任意)** — 「API ⚙」からAPIキーを設定すると claude-sonnet-5 による本物のAI台本生成に切り替わる(未設定・失敗時はテンプレートにフォールバック)
- JST時計・ステータスバー・CRT風スキャンライン演出、モバイル対応(RESEARCHパネルは折りたたみ)

## 使い方

`index.html` をブラウザで開くだけです。ビルド・依存関係・APIキーは不要。

```
open index.html
```

GitHub Pages を有効化すれば、そのままWebで公開できます。

## 注意

- RESEARCH パネルの走査ログ・件数は**デモ用のシミュレーション**です(実際にYouTube/TikTok APIへはアクセスしません)
- 台本生成はURLから商品名を推定するテンプレートベースのロジックです。実運用ではClaude APIなどのLLMに差し替えることで、商品ページの内容に即した台本生成に拡張できます
