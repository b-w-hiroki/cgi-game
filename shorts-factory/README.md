# SHORTS FACTORY

縦型ショート動画・自動生成システム風のダッシュボード(1ファイル完結のWebアプリ)。

黒×琥珀色のターミナル調UIで、以下のワークフローを再現しています。

**01 走査 → 02 解析 → 03 生成 → 04 予約**

## 機能

- **RESEARCH パネル** — バズ動画の解析本数カウンター、伸びているフック型(問題提起 / 変化・比較 / ランキング)のグラフ、YouTube / TikTok 走査ログのライブフィード
- **GENERATOR** — 商品ページのURLを入力して「生成開始」を押すと、縦型ショート用の台本を3タイプ同時生成
  - A 問題提起型
  - B ビフォーアフター型
  - C ランキング型
- 各台本は秒数タイムコード付き(フック → 展開 → CTA)で、COPYボタンでクリップボードにコピー可能
- 生成完了後、投稿予約枠(TikTok / YouTube Shorts / Reels)を表示
- JST時計・ステータスバー・CRT風スキャンライン演出

## 使い方

`index.html` をブラウザで開くだけです。ビルド・依存関係・APIキーは不要。

```
open index.html
```

GitHub Pages を有効化すれば、そのままWebで公開できます。

## 注意

- RESEARCH パネルの走査ログ・件数は**デモ用のシミュレーション**です(実際にYouTube/TikTok APIへはアクセスしません)
- 台本生成はURLから商品名を推定するテンプレートベースのロジックです。実運用ではClaude APIなどのLLMに差し替えることで、商品ページの内容に即した台本生成に拡張できます
