# cgi-game

## 勇者の試練 ～CGI冒険記～

1999年風・Windows風ウィンドウUIで遊ぶ、ブラウザ上で動作するCGI風テキストRPGです。本体は単一ファイル `index.html` で完結し、ビルドやサーバーは不要です。

> はるか遠い王国で魔王が復活した。伝説の勇者よ、今こそ立ち上がる時だ！
> ダンジョンの深淵へと踏み込み、魔王を倒して平和を取り戻せ！

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

1. タイトル画面で「▶ はじめる」を押す
2. キャラクター作成で名前（最大8文字、初期値「ユウシャ」）を入力し、職業を選んで「▶ 冒険開始！」
   - ⚔️ 戦士：HP高め、物理攻撃が得意
   - 🔮 魔法使い：MP高め、魔法攻撃が得意
   - 🗡️ 盗賊：素早さ高め、先制攻撃が得意
3. 拠点「王都アルカディア」からダンジョンへ出発する

タイトル画面の「▶ つづきから」で、セーブしたデータから再開できます（セーブデータはブラウザの localStorage に保存されます）。

## ゲームの流れ

- **街（王都アルカディア）**：ダンジョンへの出発、道具屋、宿屋、ステータス確認、セーブを行う拠点です。HP / MP / 所持金（G）/ レベルが表示されます。
- **ダンジョン**：「探索する」で進み、「階段を探す」で下の階（B2F、B3F…）へ潜ります。「街に戻る」でいつでも帰還できます。
- **戦闘**：コマンドは「⚔️ 攻撃」「🔮 魔法」「🧪 アイテム」「💨 逃げる」。敵を倒すと経験値が入り、レベルが上がります。最深部ではボス戦があり、魔王を討伐するとクリア画面になります。
- **宿屋（月光亭）**：20GでHP / MPが全回復します。
- **道具屋（鉄の盾亭）**：武器・防具などの装備とアイテムを購入できます。
- **ステータス画面**：レベル、経験値、HP、MP、攻撃力、防御力、素早さ、魔力、武器、防具、所持金、踏破最深階と、所持アイテム一覧を確認できます。
- **ゲームオーバー**：力尽きても「街に戻る」で冒険を続けられます。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | ゲーム本体（単一ファイル完結） |
| `shorts-factory/` | 縦型ショート動画の台本生成ツール群（本体とは別のツール集。詳細は `shorts-factory/README.md`） |
| `test/keys.test.cjs` | `shorts-factory/index.html` のAPIキー取り扱いに関するテスト |
| `.github/workflows/offline-test.yml` | プルリクエスト／`main` へのプッシュでテストを実行するCI |

## テスト

Node.js 22 で実行します。

```bash
node --test test/keys.test.cjs
```

## 備考

- ゲーム内では推奨環境として「Internet Explorer 6.0 以上」と表記されていますが、これは1999年風の演出です。
- セーブデータは localStorage の `retroRPG_save` キーに保存されます。ブラウザや端末を変えると引き継げません。

## 保存の検証
保存失敗は成功扱いせず、壊れた保存の読込で現在の冒険と元データを変更しません。HP0の保存は敗北復帰と同じ処理で街へ戻します。`node --test test/*.test.cjs` で回帰確認。初見3分の体験は未実測です。
